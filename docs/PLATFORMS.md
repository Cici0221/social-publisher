# 14 平台接入清单

官方资料核对日期为 2026-11-24。表中的「待实测」表示已按官方接口实现并保留独立适配器，仍需要获批应用、授权账号和真实联调。所有真实适配器均待真实账号验收，应用提交和审批状态由公司在各平台控制台核实。本地环境可为 A、B 类创建模拟账号。C 类在平台账号管理登记名称、默认语言和官方后台入口。

OAuth 应用使用 `APP_URL` 加 `/api/accounts/oauth/<平台键>` 作为回调。凭据只填服务端环境。使用开发者控制台中与应用用例对应的 ID 和 Secret，并核对目标账号的实际权限。
